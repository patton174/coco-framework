# Coco brand assets

- Primary: `#b4441f`; dark-theme accent: `#f0873a`.
- Secondary: amber `#e08a1e` for small accents, never small body text on white.
- Neutrals: `#ffffff`, `#faf6f0`, `#f3ece1`, `#cdbcae`, `#4a3529`, `#241a15`, `#1c1512`.
- Body and headings: self-hosted Newsreader Variable (serif; CJK falls back to system serif). Code: self-hosted JetBrains Mono Variable.
- Use the primary color for actions, links and active navigation. Keep cards, tables and code surfaces neutral.
- The mark (`mark-clay*.svg`, `favicon.svg`, `apple-touch-icon.png`) is two coffee beans: one standing, one lying beside it, with the crease cut out so the ground shows through. `favicon.svg` has no tile and recolours itself for dark browser chrome. The older C-arc raster/SVG assets (`logo*.svg`, `logo-<size>.png`, wordmarks and share cards) are still generated by `scripts/generate-brand.py` and have not been redrawn yet.
- Horizontal and stacked wordmarks have explicit cream backgrounds for predictable contrast. White/black/primary SVGs are transparent monochrome variants.
- `social-card.png`: 1200×630 for the website; `github-social-preview.png`: 1280×640 for GitHub Settings → General → Social preview.
- Share image SVGs are editable templates. Raster assets are generated by `scripts/generate-brand.py`; pass `--headline` to prepare release or feature cards. SVG wordmarks use installed fonts; shipped PNGs have no font dependency.
- These images describe main's 17 feature identifiers, not the module count of the v2.0.2 release.

## Copy conventions

Chinese: **少写基础设施，多写业务。** English: **Less infrastructure. More product.**

Describe a developer task before listing implementation details. Explain SPI as a replaceable interface on first use.
“一个 Starter” always means the recommended parent/BOM setup. “默认生效” refers to response wrapping, exception handling and TraceId, not databases or distributed services.
Do not claim coverage percentages, production adoption, benchmark superiority, zero configuration for every feature, or an unreleased version.
Keep Chinese and English homepage copy together in `src/data/landing.ts`; README changes go through `.github/readme/fragments/` and the renderer.
