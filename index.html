Coco Framework

高约定的 Spring Boot Web 服务端框架，快速构建生产可用的 Java 服务

快速开始 →了解框架
pom.xml
<dependency>
  <groupId>io.github.patton174</groupId>
  <artifactId>coco-spring-boot-starter</artifactId>
</dependency>
Why Coco

为什么选择 Coco

高约定，开箱即用

引入一个 starter 即可获得统一响应、全局异常处理、TraceId 链路等生产基础设施，业务代码继续使用普通的 Java / Spring 编程模型。

可插拔，可替换

每项能力通过特性开关声明式启停，每个 SPI 都能用一个 @Bean 覆盖为自己的实现。限流、幂等、锁、存储的默认实现都可替换为分布式版本。

安全默认，边界清晰

请求加解密、签名、防重放、安全响应头、SQL 防护、文件魔数校验内置且默认安全。框架负责基础设施，业务持有领域模型与认证。
