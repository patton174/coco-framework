Agent 技能

让 AI 编码助手直接会用 Coco Framework。

@patton174/coco-agent-skills 是一个零依赖的 Node 包,把框架文档、版本信息和接入能力封装成 AI Agent(Claude Code、Codex、Cursor 及国产 Agent)可直接调用的技能。Agent 不再需要你手动粘贴文档——它能语义检索、拉取整页、生成依赖片段、检测版本。

一句话价值

把"查文档、找版本号、写依赖"这些重复动作,变成 Agent 的一次工具调用。

能力总览​

能力说明
语义检索基于本地嵌入(bge-small-zh-v1.5,512 维)对全部文档做向量检索,中英双语、离线可用、无需 API key
整页获取检索命中后拉取整页文档,供 Agent 完整配置某个能力
文档发现列出全部文档页(路径、标题、URL)
依赖片段生成 Maven/Gradle 依赖片段,版本号自动填 Maven Central 最新发布版
版本检测从 Maven Central 拉取最新版本,与当前版本比对,判断是否需要升级
索引新鲜度报告文档索引的构建时间与陈旧度,支撑自动更新
一键安装为 Claude / Codex / Cursor / 通用 Agent 写入 MCP 配置与技能文件

中英双语检索​

索引同时收录中文文档与英文译文,共用一个双语嵌入模型,因此:

  • 用哪种语言提问都行 —— 中文问「如何开启分布式锁」和英文问 how to enable distributed lock 都能准确命中。
  • 返回与提问语言一致的原文 —— 英文提问返回英文页面(URL 带 /en/ 前缀),不会拿到中文段落。
  • 可显式限定语言 —— 需要时传 locale 参数(zh-Hans / en)把结果锁定到一种语言。
为什么不是纯英文模型

文档 95% 是中文。用纯英文嵌入模型时,中文查询几乎召回不到正确页面(问「如何开启分布式锁」,正确文档排在第 26 位)。换用中英双语模型后,两种语言都能命中首位。

工作方式​

技能以两种形态交付,可同时使用:

  • MCP 服务器 — 通过 stdio 暴露 7 个工具,Agent 运行时动态调用。
  • 静态技能文件 — 为各家 Agent 写入约定文件(Claude 的 SKILL.md、Cursor 的 .cursor/rules、通用 AGENTS.md),让 Agent 无需运行时也能理解框架。
