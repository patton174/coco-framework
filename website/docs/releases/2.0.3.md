# 2.0.3 版本说明

本页记录 2.0.3 发布内容；正式可用状态以 GitHub Releases 和 Maven Central 为准。

## 框架能力

相较于 2.0.2，本期主干新增或完善：

- [分页](../features/pagination.md)：统一分页与排序模型，以及 Web 参数到 MyBatis-Plus 的集成。
- [Web 运行时](../features/web-runtime.md)：CORS、安全响应头、字段校验错误及请求上下文改进。
- [存储](../features/storage.md)：可替换存储 SPI 与本地存储实现。
- [消息](../features/messaging.md)与[分布式锁](../features/lock.md)：消息集成与内置 Redis 锁存储。
- [限流](../features/rate-limit.md)：滑动窗口和令牌桶算法。
- [缓存](../features/cache.md)：Caffeine 本地缓存与 Caffeine + Redis 两级缓存。
- [通知](../features/notification.md)：可替换通知渠道。
- [验证码](../features/captcha.md)：图形、滑块、短信码 SPI，以及适用于多实例的 Redis 存储。

## 官网与文档

官网使用 `cocoframwork.dev`，更新中英文首页、品牌素材、搜索元数据和文档阅读交互。文档支持滚动渐入、阅读进度与导航反馈，并尊重系统的减少动态效果设置。

配套 MCP 包 `@patton174/coco-agent-skills` 0.2.1 更新官网链接，并重新生成中英文语义索引，包含本期能力和版本说明。npm 可用状态以 npm registry 为准。

## 升级检查

1. 确认 Maven Central 已发布 2.0.3，再将 `coco-parent` 或 BOM 版本更新为 `2.0.3`。
2. 对照所使用模块的文档检查开关、Bean 和外部服务配置；新增模块不代表全部默认启用。
3. 多实例部署显式配置共享存储，验证验证码、锁、缓存和限流行为。
4. 执行业务项目的构建与集成测试；CRUD、事务边界和业务权限仍由应用负责。
