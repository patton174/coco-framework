# Coco Framework 门面优化整改方案

> 版本：v1.0
> 日期：2026-09-07
> 范围：GitHub 项目主页 / 文档站 / SEO / 品牌视觉 / 文案体系
> 性质：整改需求文档，不含具体实现代码

---

## 一、文档概述

### 1.1 背景

Coco Framework 内核实力已达较高水准：16 万行代码、17 个功能模块、完整的 SPI 扩展体系、AI 评审陪审团、双门分支治理、Dependabot 自动化依赖维护。但对外展示层（"门面"）与内核实力严重不匹配，存在文案技术化、SEO 缺失、视觉冲击力弱、品牌识别度低等问题，导致项目吸引力与实际实力不匹配。

### 1.2 目标

将 Coco Framework 的门面从"能跑就行"提升至"与内核实力匹配的专业开源项目门面"，具体目标：

- 文案从"工程师黑话"转为"开发者共鸣"，3 秒内让访客理解项目价值
- SEO 从"几乎为零"提升至"基础完备"，搜索引擎可正常收录与展示
- 视觉从"默认 Docusaurus"提升至"有品牌辨识度的专业设计"
- 品牌识别从"无"提升至"有统一的 Logo / 配色 / 社交预览体系"

### 1.3 范围

| 模块 | 包含 | 不包含 |
|---|---|---|
| GitHub 项目主页 | README、项目描述、Topics、Social Preview | 仓库代码、Issue 模板 |
| 文档站首页 | Hero 区、功能展示区、文案、动画 | 文档内容页的具体文字 |
| SEO | meta 标签、sitemap、robots、结构化数据、Open Graph | 内容营销策略 |
| 品牌视觉 | Logo、配色体系、Social Card、favicon | 完整品牌手册 |
| 文案体系 | Slogan、副标题、功能描述、痛点表达 | API 文档文案 |

### 1.4 优先级定义

| 优先级 | 定义 | 建议完成时间 |
|---|---|---|
| P0 | 致命缺失，严重影响第一印象与可发现性 | 1 周内 |
| P1 | 重要缺失，显著影响吸引力与说服力 | 2 周内 |
| P2 | 优化项，提升专业度与长期价值 | 1 个月内 |
| P3 | 锦上添花，可根据资源情况择机实施 | 长期 |

## 二、现状诊断

### 2.1 总体评分

| 维度 | 评分（10分制） | 说明 |
|---|---|---|
| 内核实力 | 9.0 | 代码质量、功能覆盖、治理体系均达较高水准 |
| GitHub README | 4.0 | 结构完整但文案技术化、无视觉冲击、无社会证明 |
| 文档站首页 | 5.5 | 有 Hero 区和动画但文案平庸、无数字冲击、无痛点共鸣 |
| SEO | 2.0 | sitemap/robots/结构化数据/OG 均缺失，几乎为零 |
| 品牌视觉 | 3.5 | 有简单 Logo 但无 Social Preview、无统一视觉体系 |
| 文案体系 | 3.0 | 全是功能罗列，无价值主张、无情感共鸣、无差异化 |
| **门面综合** | **3.8** | **与内核 9.0 严重不匹配** |

### 2.2 核心问题归纳

```
问题一：工程师思维写门面 → 全是"我有什么功能"，没有"你为什么需要我"
问题二：SEO 几乎为零     → 搜索引擎无法有效收录，项目可发现性极低
问题三：品牌识别缺失     → 无 Social Preview、无统一视觉、分享时显示默认图
问题四：文案无冲击力     → "高约定"是内部黑话，普通开发者 3 秒内看不懂价值
问题五：社会证明为零     → 无用户案例、无 Star 数、无贡献者多样性
问题六：视觉割裂         → 首页精装、文档页毛坯，点进文档瞬间掉档次
```

### 3.3 SEO 优化

#### 3.3.1 基础 SEO 配置（P0）

**需求描述：** 补齐 SEO 基础配置，让搜索引擎可正常收录与展示。

**整改项：**

| 编号 | 整改项 | 现状 | 需求 | 验收标准 |
|---|---|---|---|---|
| SEO-001 | meta description | 仅首页有 description，内页无统一配置 | 为全站配置统一的 meta description 模板 | 首页有独立 description；文档页自动提取页面前 150 字作为 description；所有页面均有 description 标签 |
| SEO-002 | meta keywords | 无 | 配置核心关键词 | 首页包含至少 8 个关键词（Spring Boot、Java framework、分布式锁、限流、幂等、多租户、数据权限、审计日志）；文档页包含页面相关关键词 |
| SEO-003 | Open Graph 标签 | 仅有默认 image | 配置完整的 OG 标签 | 包含：og:title、og:description、og:image、og:url、og:type、og:site_name；所有页面均有完整 OG 标签 |
| SEO-004 | Twitter Card | 无 | 配置 Twitter Card | 包含：twitter:card（summary_large_image）、twitter:title、twitter:description、twitter:image；分享到 Twitter 时正确显示卡片 |
| SEO-005 | Social Card 图片 | 使用默认 docusaurus-social-card.jpg | 设计并使用自定义 Social Card | 尺寸 1200×630，包含 Logo、项目名、Slogan、关键数字；配色与项目统一；在浅色/深色背景下均清晰 |
| SEO-006 | sitemap.xml | 未安装 sitemap 插件 | 安装并配置 sitemap 插件 | 生成 sitemap.xml，包含所有文档页面 URL；提交到 Google Search Console 和 Bing Webmaster Tools |
